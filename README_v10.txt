インフルエンザレーダー（新潟県） front-end patch v10

目的:
- ヒーロー右上の「新潟県シルエット風アクセント」を、偽のクリップパス形状ではなく、
  実際の新潟県GeoJSONから生成した正しい県形状に差し替える。

変更ファイル:
- index.html
- app.js
- styles.css

主な変更点:
1. hero 右上アクセントを SVG コンテナ化
2. 既存の GeoJSON を再利用して、新潟県の外形（各市町村ポリゴンの集合）を SVG として描画
3. 画像/素材の追加不要。既存の GEOJSON_URL をそのまま使う
4. 県名ラベルを別要素にして見やすく調整

補足:
- 県シルエットは、地図本体で使用しているのと同じ新潟県市町村GeoJSONをもとに生成しています。
- そのため、背景アクセントも実際の新潟県形状に一致します。
