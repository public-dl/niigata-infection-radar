# 新潟感染症レーダー：インフルエンザ自動収集

新潟県「感染症情報（週報）」から、各週の **5類感染症定点把握対象疾患報告数 Excel** を取得し、
インフルエンザの「県全体」＋13公表区分の定点当たり報告数を履歴化するためのパッケージです。

## 13公表区分

- 村上：村上市・関川村・粟島浦村
- 新発田：新発田市・阿賀野市・胎内市・聖籠町
- 新潟市：新潟市
- 新津：五泉市・阿賀町
- 三条：三条市・加茂市・燕市・弥彦村・田上町
- 長岡：長岡市・小千谷市・見附市・出雲崎町
- 魚沼：魚沼市
- 南魚沼：南魚沼市・湯沢町
- 十日町：十日町市・津南町
- 柏崎：柏崎市・刈羽村
- 上越：上越市・妙高市
- 糸魚川：糸魚川市
- 佐渡：佐渡市

## 初回バックフィル

GitHub の Actions で **Backfill influenza history** を手動実行します。

処理内容:
1. 県の週報一覧から2025年以降の週ページを列挙
2. 各ページからExcelリンクを取得
3. Excel内の「インフルエンザ」「定点当たり」行を探索
4. 県全体と13地域を `data/influenza_history.json` に保存
5. 読み取れなかった週は `data/backfill_failures.json` に記録

過去値を推測・補間しません。取得できない週は欠損として残します。

## 毎週更新

`.github/workflows/update-influenza.yml` が毎週木曜19:30（JST）に動きます。
新しい週だけ取得し、履歴JSONへ追記します。

## ローカル実行

```bash
pip install -r requirements.txt
python scripts/backfill.py --start-year 2025
python scripts/update.py
```

## Web側で使うデータ

`data/influenza_history.json`

各週は以下の形式です。

```json
{
  "year": 2026,
  "week": 36,
  "start": "2026-08-31",
  "end": "2026-09-06",
  "label": "R8/8/31–9/6",
  "prefecture": 6.13,
  "regions": {
    "村上": 13.0,
    "新潟市": 8.56
  },
  "topic": "インフルエンザの流行期に入っています...",
  "source_page": "...",
  "source_excel": "..."
}
```

このJSONをグラフ・地図・ランキング・前年同期比の共通データソースにします。

## 注意

県Excelのレイアウト変更に備え、パーサーは固定セル番地ではなく、
「インフルエンザ」「定点当たり」「全県」「13地域名」を探索する方式です。
それでも構造変更で失敗した週は failure ログに残るため、誤った数値を公開しません。
