v24 地域別地図・週次タイムスライダー版

追加機能:
- 2025年第1週〜最新週までの週次スライダー
- スライダー操作で地図の青/黄/赤/紫が週ごとに切り替わる
- ◀ / ▶ で1週ずつ移動
- 「再生」で時系列アニメーション
- 「一時停止」で停止
- 最新週から再生を押した場合は最初の週からスタート
- 「最新へ」で現在の週へ戻る
- 地図上部に選択中の週と日付レンジを表示
- 地域別ランキングも選択週に連動
- 地図ツールチップにも選択週を表示

色分け:
- 1未満: 青
- 1以上10未満: 黄
- 10以上30未満: 赤
- 30以上: 紫

主な差し替え:
- index.html
- app.js
- styles.css
